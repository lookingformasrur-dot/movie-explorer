# Movie Explorer

Movie Explorer is a responsive React web application where users can explore movies and TV shows, search by title, and view detailed information about each show.

## Features

* Responsive navigation bar
* Movie/TV show listing
* Dynamic search by title
* Movie cards with poster, title, rating, and release date
* Detailed movie information modal
* Modal close button
* Click outside the modal to close it
* Loading and error states
* Responsive design for mobile, tablet, and desktop
* Official website link for available shows

## Technologies Used

* React
* JavaScript
* CSS
* Vite
* TVmaze API

## API

This project uses the TVmaze API:

* All shows: `https://api.tvmaze.com/shows`
* Search shows: `https://api.tvmaze.com/search/shows?q=:query`

## Installation

Clone the repository:

```bash
git clone https://github.com/lookingformasrur-dot/movie-explorer.git
```

Go to the project folder:

```bash
cd movie-explorer
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Build

To create a production build:

```bash
npm run build
```
